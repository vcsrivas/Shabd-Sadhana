Updating the words

To update the list for everyone, replace words.xlsx in the GitHub repository with the new file (same name, same layout: one tab per topic with columns headed Easy, Moderately Difficult and Difficult). The app picks it up the next time it is opened. Words already shown will not be repeated.

About meanings

Meanings, parts of speech, pronunciation and usage examples come from the free Free Dictionary API, which draws on Wiktionary. Some rare words and phrases are not in it, and not every meaning has a usage example. The Oxford Learner's button on every word opens its entry on oxfordlearnersdictionaries.com.
